# 截图与演示素材

这个目录用来放 README 里展示的界面截图。GitHub 仓库首页的观感，
很大程度取决于这里有没有真东西。

## 建议放两张

| 文件名 | 内容 | 为什么值得截 |
| --- | --- | --- |
| `screenshot-main.png` | 完整界面，能看到顶部步骤条、结论、图表、表格与右侧执行轨迹 | 一张图说明"这是个真的能用的系统" |
| `screenshot-validation.png` | 模型生成的 SQL 被安全校验拦下、并带着原因重写的画面 | 这是本项目最有辨识度的一幕：约束不靠模型自觉 |

尺寸建议 1440×900，浏览器缩放到 100%，截图前把窗口宽度拉到截图尺寸。
如果要放到 README 里，直接用相对路径引用即可：

```markdown
![主界面](docs/screenshot-main.png)
```

根目录 `README.md` 的「界面」一节已经留好了位置，把那里的 HTML 注释换成图片引用就行。

## 顺带一提

`VITE_DEMO=true npm run build` 之后把 `frontend/dist/` 发到 GitHub Pages，
可以让访客直接点开玩——没有后端也能看完整界面。
这条路径比截图更有说服力，建议在仓库简介里附上链接。
